# Mango Desk — remaining features

The following features are planned but not yet built. Implement them one at a
time, with approval before starting each feature.

- [ ] **Focus queue** — pin a small set of next actions and reorder them.
- [ ] **Search and filters** — find work by title, workstream, status, priority,
  and date.
- [ ] **Labels and notes** — add context to tasks without leaving the local
  workspace.
- [ ] **Keyboard navigation** — add shortcuts for quick capture, search, and
  common task actions.
- [ ] **Backup and restore** — export and import a human-readable workspace
  file.
- [ ] **Progress insights** — summarize completed work and trends over a
  selectable period.
- [ ] **Preferences** — personalize accent colors, interface density, and
  start-of-week settings.
